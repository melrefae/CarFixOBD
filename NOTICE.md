# Third-party data

## DTC definitions (assets/databases/dtc_definitions_open.json)
Built from the source-data text files of https://github.com/Wal33D/dtc-database
(MIT License, Copyright (c) 2024 Wal33D (Waleed Judah)). The license text is in
assets/databases/dtc_definitions_open.LICENSE.txt. Only code-to-definition text is used.
Definitions are English only. Manufacturer-specific definitions are shown per brand.
The Arabic entries in dtc_codes_ar.json and the in-app knowledge base are separate, written by this project.
